# teleport-toys
Small projects and experiments from the Teleport team. (not officially supported, use at your own risk)

## Projects

- [`beams-vscode`](beams-vscode/) — VS Code extension to manage and connect to Teleport Beams: create, monitor, and SSH into ephemeral agentic runtimes.
- [`beams-slack-plugin`](beams-slack-plugin/) — Slack bot that does work in Teleport Beams as the person who asked: coding agents, quick answers, and beam management.
- [`data-clean-room`](data-clean-room/) — People-data clean room on Teleport Beams: computes org-health metrics and Claude-written insights in a disposable Beam, and releases only what passes a privacy gate.
